# 🎬 ZOET Web

نسخة الويب السريعة والمستقلة من منصة **ZOET**، تعمل بالكامل عبر المتصفح باستخدام تقنية **Rust WebAssembly** مع واجهة زجاجية داكنة وتجربة سينمائية متكاملة.

---

### 🌐 رابط الوصول المباشر (GitHub Pages)
👉 **[https://xrtm8.github.io/ZOET-Web/](https://xrtm8.github.io/ZOET-Web/)**

> 💡 **تثبيت كتطبيق (PWA):** يمكنك تثبيت الموقع مباشرة كتطبيق على هاتفك (iPhone / Android) أو على حاسوبك من خلال خيار "إضافة إلى الشاشة الرئيسية" أو "Install App" في المتصفح.

---

### ✨ أبرز المميزات:
1. **🦀 محرك Rust WebAssembly عالي الأداء:**
   - واجهة مستخدم فائقة الاستجابة وسريعة التشغيل.
2. **🎨 استوديو فلاتر الفيديو (Video Filters & Shaders):**
   - أوضاع تلوين فورية: عادي، أنمي (Anime Vivid)، سينما دافئة (Cinema Warm)، وظلال عميقة.
   - اختصار الكيبورد: `V`.
3. **🔤 تخصيص ألوان وتنسيق الترجمة:**
   - التبديل الفوري بين ألوان الترجمة: أصفر سينمائي، أبيض، سماوي، أخضر نعناعي، وكهرماني.
   - اختصار الكيبورد: `Shift + C`.
4. **🎮 دعم كامل لأيدي التحكم (Gamepad):**
   - يد تحكم Xbox و PlayStation والريموتات عبر الـ Gamepad API.
5. **🔊 مضخم الصوت الرقمي حتى 300%:**
   - مضخم مدمج باستخدام Web Audio API للمقاطع الصوتية الهادئة.
6. **📥 دعم سحب وإفلات الترجمة الخارجية (.srt / .vtt):**
   - ضبط توقيت الترجمة بالأجزاء من الثانية باستخدام `[` و `]`.

---

### تشغيل المصادر على الموقع

سينمانا يتصل من شبكة المشاهد حسب توفّره لديها. قرمزي يتصل تلقائياً عند تفعيل خدمته المستضافة من طرف مشرف الموقع.

يضبط مشرف الموقع قيمة `zoet-api-origin` في `index.html` على عنوان HTTPS المنشور لخدمة `worker/worker.js`.

### 🚀 النشر والتحديث التلقائي
المستودع مجهز بـ **GitHub Actions Workflow** يقوم تلقائياً ببناء ونشر أي تحديثات على فرع `main` مباشرة إلى **GitHub Pages**.
